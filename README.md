# 有機野菜サイト リニューアルプロジェクト

職業訓練校のWeb講座における、既存サイトのリニューアル課題リポジトリです。

## 1. プロジェクト概要

本プロジェクトは、既存のWebサイトを対象に、現在のWeb標準やユーザー動向に合わせた「再構築（リニューアル）」を行う実践的な訓練です。
テーマとして「有機野菜（organic-vegetables）」を取り扱い、デザインからコーディング、動的機能の実装までの一連のプロセスを構築しました。

## 2. 開発環境の構築と複数端末でのバージョン管理

本講座の受講にあたり、コーディングスキルだけでなく、実務に即した開発環境の運用方法を自ら実践・修得しました。

- **環境構築**: 訓練校のPCにGitが未導入であったため、自身でGit環境のインストールから実施しました。
- **マルチデバイス管理**: GitHubを用いて、自宅PCと訓練校PC間でソースコードを同期しながら、複数環境でのバージョン管理を実践しました。

## 3. 制作プロセス

1. **デザイン・設計（完了）**
   既存サイトの課題を洗い出し、リニューアルに向けたワイヤーフレーム（設計図）を作成。
2. **コーディング・動的機能実装（完了）**
   HTML/CSSを用いたセマンティックなマークアップとレスポンシブ対応。
   JavaScriptを用いたユーザー体験（UX）を高める動的ギミックの実装。

## 4. 主要な実装機能

本プロジェクトでは、以下の機能を自力で実装・最適化しました。

- **メインビジュアルのスライダー（JavaScript）**: 背景画像を時間経過でフェード切り替えする動的演出。
- **丸アイコンのスクロールフェードイン（JavaScript）**: 画面のスクロールを検知して要素をふわっと浮き上がらせる演出。
- **ハンバーガーメニュー（JavaScript / CSS）**: スマホ表示時におけるナビゲーションの隠蔽と引き出し機能。
- **セクション画像のフェードイン（CSSアニメーション）**: ページ読み込み時に写真を優しく表示させるアニメーション。
- **レスポンシブ対応・レイアウト最適化（CSS）**:
  - スマホ閲覧時の可読性を担保するボタンサイズ・配置の調整。
  - スクロール時の視線の流れを美しく整えるため、特定のセクションにリバースカラム（`flex-direction: column-reverse`）を採用。
  - 背景画像と重なっても三本線やロゴが埋もれないよう、白いドロップシャドウ（`filter: drop-shadow`）を適用。
