# 有機野菜サイト リニューアルプロジェクト

職業訓練校のWeb講座における、既存サイトのリニューアル課題リポジトリです。

## 1. プロジェクト概要
本プロジェクトは、既存のWebサイトを対象に、現在のWeb標準やユーザー動向に合わせた「再構築（リニューアル）」を行う実践的な訓練です。
テーマとして「有機野菜（organic-vegetables）」を取り扱い、デザインからコーディングまでの一連のプロセスを構築します。

## 2. 開発環境の構築と複数端末でのバージョン管理
本講座の受講にあたり、コーディングスキルだけでなく、実務に即した開発環境の運用方法を自ら実践・修得しています。
- **環境構築:** 訓練校のPCにGitが未導入であったため、自身でGit環境のインストールの実施から行いました。
- **マルチデバイス管理:** 訓練校のPCと自宅のMacの双方でGit管理を徹底し、GitHubを経由した安全なデータ共有・同期体制を構築。実務のチーム開発に準ずるバージョン管理を一人で体現しています。

## 3. 制作プロセス・現在の進捗
1. **デザイン・設計（完了）**
   - 既存サイトの課題を洗い出し、リニューアルに向けたワイヤーフレーム（設計図）を作成。
2. **コーディング（現在進行中 🚀）**
   - 作成したワイヤーフレームを基に、HTML/CSSを用いた実装を開始。

## 4. 開発環境・ツール
- **エディタ:** Visual Studio Code
- **バージョン管理:** Git / GitHub
